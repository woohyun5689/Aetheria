# Aetheria Unity

Unity 6000.3.15f1용으로 만든 Aetheria 플레이어블 프로젝트입니다.

## 웹 플레이

- [Aetheria WebGL 실행](https://server.lionwolfgang.cloud/Aethria)
- 저장소 내 빌드 위치: `WebGL/Aethria`

- Unity Hub에서 이 폴더를 프로젝트로 추가해서 열면 됩니다.
- `Assets/Scripts/AetheriaGame.cs`가 런타임 UI와 게임 로직을 생성합니다.
- 기존 웹 버전은 `Assets/StreamingAssets/WebVersion`에 보관했습니다.
- 캐릭터 이미지는 `Assets/Resources/Portraits`에 넣었습니다.
