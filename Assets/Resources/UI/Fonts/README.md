# Aetheria UI Fonts

The game bundles these Korean UI fonts so its typography does not depend on
fonts installed on the player's operating system.

- `GowunDodum-Regular.ttf`: body copy, compact labels, and buttons
- `GowunBatang-Bold.ttf`: large headings and display labels

Both font families are distributed under the SIL Open Font License 1.1.
The complete license texts are included beside the font files.

Sources:

- https://github.com/google/fonts/tree/main/ofl/gowundodum
- https://github.com/google/fonts/tree/main/ofl/gowunbatang
