# Aetheria WebGL Build

- 웹 실행: https://server.lionwolfgang.cloud/Aethria
- 시작 파일: `index.html`
- 로컬 실행: `Start_Aetheria_Local.cmd`
- Unity 버전: `6000.3.15f1`
- 화면 기준: `1600x900` / 16:9 반응형 캔버스

`Build`, `StreamingAssets`, `TemplateData` 폴더는 WebGL 실행에 필요한 배포 파일입니다.
Windows에서는 `Start_Aetheria_Local.cmd`를 더블클릭하면 사용 가능한 로컬 포트를 찾아 브라우저를 자동으로 엽니다.
